- `Ctrl/Cmd+Shift+P` - TTS播放/暂停
- `Ctrl/Cmd+Shift+S` - TTS停止
- `M` - 切换边距宽度
- `L` - 切换行间距
- `S` - 切换侧边栏（已有Ctrl/Cmd+B）
- `Home/End` - 章节开头/结尾
- `PgUp/PgDn` - 跳转10页

**建议**：
- 补充这些快捷键的实现
