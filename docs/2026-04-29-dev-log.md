## 三、数据持久化 + WebDAV 同步

### 问题
`bookMiniReviewService` 和 `smartReviewSystem` 用内存 Map 存数据，`saveCacheToSettings()` 调用的方法在 settings store 中不存在，数据从未被持久化，刷新即丢失。

### 架构设计

```
启动 → main.tsx 调用 initializeFromDB()
      → SQLite → 内存 Map → settings store (withPersist → 磁盘)

写入 → 内存 Map + settings store + SQLite (三处同步)
      → SQLite 表在 SYNC_TABLES 中 → WebDAV 同步自动包含

读取 → 内存 Map (最快)
      → 刷新后 → SQLite 恢复到 Map
```

## 数据库表结构

### mini_reviews

| 列 | 类型 | 说明 |
|----|------|------|
| id | TEXT PK | 主键 |
| book_id | TEXT FK | 关联书籍 |
| content | TEXT | 微评内容 |
| generated_at | INTEGER | 生成时间戳 |
| rating | INTEGER | 评分（可选） |
| source | TEXT | 来源：douban / openlibrary / ai |
| updated_at | INTEGER | 更新时间戳 |

### review_items

| 列 | 类型 | 说明 |
|----|------|------|
| id | TEXT PK | 主键 |
| book_id | TEXT FK | 关联书籍 |
| chapter_id | TEXT | 章节标识 |
| chapter_title | TEXT | 章节标题 |
| scheduled_date | INTEGER | 计划复习时间 |
| completed_date | INTEGER | 完成时间（可选） |
| quality | TEXT | 评级：excellent / good / fair / poor |
| status | TEXT | 状态：pending / completed / skipped |
| review_count | INTEGER | 已复习次数 |
| next_review_date | INTEGER | 下次复习时间（可选） |
| notes | TEXT | 笔记（可选） |
| updated_at | INTEGER | 更新时间戳 |
