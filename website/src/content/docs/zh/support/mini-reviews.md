## 概述

微评是 AI 生成的简洁快照，捕捉您阅读内容的精髓。它们提供快速洞察、发人深省的钩子和难忘的要点，增强您的阅读体验。

## 什么是微评？

微评是由 AI 生成的简短、聚焦的评论，突出书籍的不同方面：
- **钩子（Hook）** - 吸引读者的开场白
- **问题（Question）** - 引发深思的问题
- **共鸣（Resonance）** - 情感连接和个人见解
- **轶事（Anecdote）** - 文本中有趣的故事或例子

每个微评都设计得简洁而有影响力，帮助您记住和反思关键时刻。

## 微评类型

### 1. 钩子（Hook）
**目的**：用引人入胜的开场吸引注意力

**特点**：
- 迷人的陈述
- 令人惊讶的事实
- 有力的引用
- 戏剧性的揭示

**示例**："在这一章中，作者揭示了关于人性的惊人真相，挑战了我们对一切已知事物的认知。"

### 2. 问题（Question）
**目的**：激发批判性思考和反思

**特点**：
- 开放式询问
- 哲学提示
- 个人应用问题
- 比较分析

**示例**："如果你应用这段讨论的原则，你的生活将如何改变？"

### 3. 共鸣（Resonance）
**目的**：与文本建立情感连接

**特点**：
- 个人反思
- 普遍主题
- 情感反应
- 可关联的经历

**示例**："这一刻捕捉到了我们都面临的职责与欲望之间的普遍斗争。"

### 4. 轶事（Anecdote）
**目的**：突出有趣的故事和例子

**特点**：
- 难忘的事件
- 说明性例子
- 历史平行
- 角色洞察

**示例**："作者分享了一个关于科学家通过偶然发现取得突破的迷人故事。"

## 使用微评

### 查看微评

微评出现在以下几个地方：
1. **统计仪表板** - 查看当前书籍的最新微评
2. **书籍详情** - 访问特定书籍的所有微评
3. **智能回顾面板** - 浏览整个图书馆的精选微评

### 生成微评

微评在以下情况下自动生成：
- 完成章节时
- 达到重要里程碑时
- 手动触发生成时
- AI 检测到值得注意的段落时

**手动生成**：
1. 打开一本书
2. 导航到统计或智能回顾面板
3. 点击"生成微评"
4. 选择类型（钩子/问题/共鸣/轶事）
5. 等待 AI 生成（通常 5-10 秒）

### 自定义默认类型

设置您偏好的微评类型：
1. 前往 **设置 → 阅读**
2. 找到 **微评设置**
3. 选择默认类型：钩子、问题、共鸣或轶事
4. 保存设置

当生成未明确选择的微评时，将使用默认类型。

## 管理微评

### 固定微评

固定重要的微评以保持它们在顶部：
1. 找到想要固定的微评
2. 点击图钉图标 📌
3. 固定的微评在列表中首先显示
4. 再次点击取消固定

### 评价微评

提供微评质量的反馈：
- 👍 对有用的微评点赞
- 👎 对不相关的微评点踩
- 您的评价有助于改善未来的生成

### 删除微评

删除您觉得无用的微评：
1. 将鼠标悬停在微评上
2. 点击删除/垃圾桶图标
3. 确认删除
4. 删除的微评无法恢复

## 微评功能

### AI 驱动生成

微评使用高级 AI 来：
- 分析文本上下文
- 识别关键主题
- 生成相关见解
- 保持与书籍语气的一致性

### 上下文感知

AI 考虑：
- 当前章节内容
- 之前的章节
- 书籍类型和风格
- 您的阅读历史
- 过去的微评（避免重复）

### 长度优化

微评针对简洁性进行了优化：
- 通常 50-150 个字符
- 简洁而有意义
- 易于快速浏览
- 完美适合社交分享

### 多语言支持

微评支持所有语言：
- 以书籍的语言生成
- 可以根据需要翻译
- 保持文化背景
- 适应写作风格

## 故障排除

### 微评未生成

**问题**：点击生成无反应或显示错误。

**解决方案**：
1. 验证 AI 提供商已配置（设置 → AI）
2. 检查网络连接
3. 确保书籍已向量化（用于语义上下文）
4. 尝试不同的 AI 模型
5. 检查 API 配额/积分

### 微评质量差

**问题**：微评通用、不相关或重复。

**解决方案**：
1. 给差评（点踩）以训练 AI
2. 删除并重新生成
3. 尝试不同的微评类型
4. 移动到不同的章节
5. 提供更具体的反馈

### 缺少微评类型

**问题**：无法选择某些微评类型。

**解决方案**：
1. 检查设置中启用的类型
2. 更新 ReadAny 到最新版本
3. 验证 AI 模型支持所有类型
4. 某些类型可能不适合所有类型

### 同步问题

**问题**：微评未在设备间同步。

**解决方案**：
1. 检查同步状态（设置 → 同步）
2. 手动强制同步
3. 验证 WebDAV/S3 配置
4. 检查同步冲突
5. 查看同步日志中的错误

## 隐私和数据

### 数据存储
- 微评存储在您的设备本地
- 包含在数据库备份中
- 通过您配置的同步方法同步
- 不发送到 ReadAny 服务器

### AI 处理
- 文本仅发送到您选择的 AI 提供商
- ReadAny 不保留任何数据
- API 密钥安全存储
- 您可以控制使用哪个提供商

### 导出选项

微评可以随以下内容导出：
- 完整标注导出
- 阅读统计
- 图书馆元数据
- 多种格式（Markdown、JSON 等）
