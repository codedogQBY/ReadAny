## 概述

预热是一项智能功能，在您接触文本之前准备 AI 上下文，使苏格拉底对话和 AI 辅助更加相关和有洞察力。本指南解释如何为您的阅读风格选择和使用合适的预热策略。

## 什么是预热？

预热允许 AI：
- **分析即将阅读的内容** - 在您阅读之前
- **基于章节主题准备相关问题** - 提前准备
- **建立上下文理解** - 提供更好的响应
- **通过预加载信息优化 AI 性能** - 提升体验

把它想象成 AI"提前阅读"，以便更好地为您的问题和讨论做准备。

## 为什么要使用预热？

### 优势
✅ **更相关的问题** - AI 更好地理解上下文  
✅ **更快的响应** - 上下文已预加载  
✅ **更深入的见解** - AI 有时间分析  
✅ **更流畅的体验** - 无需等待分析  
✅ **更好的学习** - 更有针对性的指导  

### 最重要的场景
- 复杂的技术书籍
- 密集的哲学文本
- 不熟悉的科目
- 批判性分析会话
- 学习和考试准备

## 预热策略

ReadAny 提供三种预热策略，每种都针对不同的阅读风格和需求设计。

### 1. 自动策略（Auto Strategy）

**工作原理**：每个新章节自动激活，无需询问。

**最适合**：
- 苏格拉底模式的初学者
- 复杂或不熟悉的文本
- 希望获得最大支持的学习者
- 需要深入分析的学习会话

**行为**：
- 每次章节更改时触发
- 显示预热进度指示器
- 自动准备完整上下文
- 无需用户干预

**优点**：
- ✅ 最大的 AI 准备
- ✅ 一致的体验
- ✅ 无需手动步骤
- ✅ 最适合学习

**缺点**：
- ❌ 使用更多 API 调用
- ❌ 可能感觉侵入性强
- ❌ 章节转换较慢
- ❌ 更高的 API 成本

**配置**：
```
设置 → AI → 苏格拉底设置
├─ 启用预热：✓
└─ 预热策略：自动
```

### 2. 智能策略（Smart Strategy）

**工作原理**：仅在您尚未看过本书的预热对话框时激活。

**最适合**：
- 常规读者
- 平衡效率和支持
- 熟悉苏格拉底模式的用户
- 混合阅读（休闲 + 学习）

**行为**：
- 第一章：显示预热对话框
- 后续章节：静默工作
- 记住每本书的偏好
- 适应您的模式

**优点**：
- ✅ 一次性解释
- ✅ 首次使用后静默操作
- ✅ 良好的功能平衡
- ✅ 高效的 API 使用

**缺点**：
- ❌ 需要初始设置
- ❌ 可能让初次用户困惑
- ❌ 控制不如手动策略
- ❌ 不完全自动化

**配置**：
```
设置 → AI → 苏格拉底设置
├─ 启用预热：✓
└─ 预热策略：智能
```

**首次体验**：
1. 打开启用苏格拉底模式的书籍
2. 出现预热对话框解释功能
3. 选择是否启用预热
4. 后续章节根据您的选择静默工作

### 3. 手动策略（Manual Strategy）

**工作原理**：从不自动激活；由您决定何时预热。

**最适合**：
- 高级用户
- 休闲阅读会话
- 希望完全控制的用户
- 关注 API 成本的读者

**行为**：
- 从不自动触发
- 工具栏中提供预热按钮
- 用户明确启动预热
- 完全控制时机

**优点**：
- ✅ 完全用户控制
- ✅ 最小 API 使用
- ✅ 无干扰
- ✅ 最低成本

**缺点**：
- ❌ 需要手动操作
- ❌ 容易忘记
- ❌ 支持不太一致
- ❌ 可能错过机会

**配置**：
```
设置 → AI → 苏格拉底设置
├─ 启用预热：✓
└─ 预热策略：手动
```

**如何触发**：
1. 在阅读器工具栏中寻找预热按钮
2. 当您希望 AI 准备时点击
3. 等待预热完成
4. 继续阅读，享受增强的 AI 体验

## 选择合适的策略

### 决策指南

**选择自动策略如果**：
- 您是苏格拉底模式的新手
- 阅读复杂教科书
- 准备考试
- 希望获得最大 AI 支持
- API 成本不是问题

**选择智能策略如果**：
- 您是常规读者
- 混合休闲和学习阅读
- 希望平衡体验
- 偏好效率
- 中等 API 预算

**选择手动策略如果**：
- 您是高级用户
- 主要是休闲阅读
- 希望完全控制
- 关注 API 成本
- 偏好最小 AI 干预

### 按书籍类型

| 书籍类型 | 推荐策略 | 原因 |
|-----------|---------------------|--------|
| 教科书 | 自动 | 需要彻底准备 |
| 哲学 | 自动 | 复杂概念受益于上下文 |
| 小说 | 智能 | 平衡沉浸感和支持 |
| 自助类 | 智能 | 实际应用重点 |
| 新闻/文章 | 手动 | 快速阅读，不需要深度 |
| 参考书 | 手动 | 查询式阅读 |

## 有效使用预热

### 最佳实践

#### 对于自动策略
1. **让它工作** - 不要中断预热
2. **回顾准备的问题** - 查看 AI 认为重要的内容
3. **提供反馈** - 评价问题的相关性
4. **根据需要调整** - 如果太侵入则切换策略

#### 对于智能策略
1. **注意第一个对话框** - 做出明智的选择
2. **记住您的决定** - 它适用于整本书
3. **尝试不同的书籍** - 每本书有独立的设置
4. **如有需要可切换** - 必要时在书中途更改策略

#### 对于手动策略
1. **养成习惯** - 在章节开始时预热
2. **观察线索** - 在困难部分之前预热
3. **一致使用** - 定期预热改善结果
4. **监控效果** - 跟踪手动触发是否有帮助

### 时机提示

**何时预热**：
- ✅ 新章节开始
- ✅ 困难段落之前
- ✅ 阅读中断后
- ✅ 切换主题时
- ✅ 讨论会话之前

**何时不预热**：
- ❌ 略读或速读
- ❌ 重读熟悉内容
- ❌ 查找特定事实
- ❌ 随意浏览
- ❌ 时间受限的会话

- ⏱️ 估计剩余时间

1. 打开苏格拉底面板
2. 查找预热状态部分
3. 查看：
   - 上次预热的章节
   - 预热持续时间
   - 准备的上下文项目
   - 使用的 API 调用

### 性能指标

跟踪预热效果：
- 问题相关性评分
- 响应质量评级
- 与无预热相比节省的时间
- 每次会话的 API 成本

## 故障排除

### 预热未激活

**问题**：预热未在预期时启动。

**解决方案**：
1. 验证设置中已启用预热
2. 检查策略选择（自动/智能/手动）
3. 对于智能策略：清除"已显示对话框"标志
4. 对于手动策略：寻找预热按钮
5. 确保 AI 提供商已配置
6. 检查网络连接

### 预热太慢

**问题**：预热花费太长时间。

**解决方案**：
1. 检查网络速度
2. 尝试更快的 AI 模型
3. 如果可能，减少章节长度
4. 在休息期间预热
5. 考虑切换到智能/手动策略

### 预热使用太多 API 调用

**问题**：频繁预热导致高 API 成本。

**解决方案**：
1. 切换到智能或手动策略
2. 为休闲阅读禁用预热
3. 为预热使用更便宜的 AI 模型
4. 批量预热会话
5. 定期监控 API 使用

### 预热对话框反复出现

**问题**：智能策略反复显示对话框。

**解决方案**：
1. 在对话框中做出明确选择
2. 检查设置是否保存
3. 清除浏览器/应用缓存
4. 更新 ReadAny 到最新版本
5. 如果持续存在，切换到自动或手动策略
