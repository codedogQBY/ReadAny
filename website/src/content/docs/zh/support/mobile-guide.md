## 概述

ReadAny 现已支持移动设备！本指南涵盖在 iOS 和 Android 上使用 ReadAny 所需了解的所有内容，包括移动端特定功能和优化。

## 平台支持

### iOS
- **最低版本**：iOS 15.0+
- **设备**：iPhone、iPad

## 移动端特定功能

### 1. 浮动 TTS 气泡 🎈

**是什么**：显示 TTS 播放状态并提供快速控制的浮动气泡。

**功能**：
- TTS 播放期间始终可见
- 快速播放/暂停切换
- 向前/向后跳过按钮
- 拖动重新定位
- 点击展开完整控制

**如何使用**：
1. 开始 TTS 播放
2. 浮动气泡自动出现
3. 拖动到首选位置
4. 点击展开控制
5. 停止 TTS 时关闭

**最适合**：
- 听书时多任务处理
- 快速访问 TTS 控制
- 后台收听

### 2. TTS 迷你播放器 🎵

**是什么**：与设备媒体控件集成的紧凑型 TTS 播放器。

**功能**：
- 锁屏控制
- 通知中心集成
- 蓝牙耳机控制
- 后台播放
- 重新打开应用时自动恢复

**如何使用**：
1. 开始 TTS 播放
2. 锁定设备或切换应用
3. 使用系统媒体控制
4. 从锁屏或通知控制
5. 重新打开应用恢复

**最适合**：
- 通勤时收听
- 锻炼会话
- 睡前阅读
- 长时间收听会话

### 3. 标签管理面板 🏷️

**是什么**：用于管理书籍标签的移动优化界面。

**功能**：
- 滑动编辑标签
- 快速创建标签
- 可视化标签浏览器
- 批量标签操作
- 按标签搜索和过滤

**如何使用**：
1. 前往图书馆屏幕
2. 点击标签按钮
3. 在面板中查看所有标签
4. 点击标签过滤书籍
5. 长按编辑/删除

**最适合**：
- 组织大型图书馆
- 快速书籍分类
- 按主题查找书籍
- 管理阅读列表

### 4. WebDAV 导入浏览器 📚

**是什么**：用于从 WebDAV 服务器导入书籍的集成文件浏览器。

**功能**：
- 浏览 WebDAV 目录
- 预览书籍元数据
- 批量导入选择
- 进度跟踪
- 冲突解决

**如何使用**：
1. 点击图书馆中的导入按钮
2. 选择"WebDAV 导入"
3. 连接到您的 WebDAV 服务器
4. 浏览并选择书籍
5. 点击下载

**最适合**：
- 从云存储导入
- 访问远程图书馆
- 同步书籍收藏
- 备份恢复

### 5. 向量化队列 ⚡

**是什么**：用于在移动设备上管理书籍向量化的智能队列系统。

**功能**：
- 自动队列管理
- 电池感知处理
- 仅 WiFi 选项
- 进度通知
- 暂停/恢复功能

**如何使用**：
1. 正常导入书籍
2. 向量化自动开始（如果启用）
3. 在通知中监控进度
4. 如需节省电池可暂停
5. 方便时恢复

**最适合**：
- 大型图书馆导入
- 电池节约
- 离线准备
- 语义搜索就绪

## 故障排除移动端问题

### 应用崩溃

**如果应用崩溃**：
1. 强制关闭并重启
2. 检查更新
3. 清除应用缓存
4. 如果持续存在则重新安装
5. 附带崩溃日志报告

### TTS 不工作

**如果 TTS 不起作用**：
1. 检查系统音量
2. 验证 TTS 权限
3. 重启 TTS 服务
4. 尝试不同的语音
5. 检查蓝牙连接

### 同步问题

**如果同步失败**：
1. 检查网络连接
2. 验证 WiFi 设置
3. 测试 WebDAV 连接
4. 检查存储空间
5. 重试手动同步

### 性能问题

**如果应用缓慢**：
1. 关闭后台应用
2. 清除缓存
3. 减小图书馆大小
4. 禁用动画
5. 重启设备

## 常见问题

### 我可以离线使用 ReadAny 吗？

可以！一旦导入书籍，您就可以离线阅读。TTS 使用系统语音工作。同步需要互联网。

### 它可以在平板上工作吗？

当然！ReadAny 针对手机和平板都进行了优化，具有自适应布局。

### 它需要多少存储空间？

取决于您的图书馆。典型书籍：1-5MB。根据图书馆大小计划 100MB-1GB。

### 我可以在移动端和桌面端之间同步吗？

可以！使用 WebDAV 或 S3 同步来保持跨设备的进度和标注同步。

### 设备数量有限制吗？

没有限制！在您想要的任意多台设备上安装。同步保持所有内容一致。
