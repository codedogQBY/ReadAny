## 全局快捷键

这些快捷键在整个应用程序中都有效：

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl/Cmd + O` | 打开/导入书籍 |
| `Ctrl/Cmd + F` | 在图书馆中搜索 |
| `Ctrl/Cmd + ,` | 打开设置 |
| `Ctrl/Cmd + Q` | 退出 ReadAny |
| `F1` | 打开帮助文档 |

## 图书馆视图快捷键

| 快捷键 | 操作 |
|----------|--------|
| `↑` / `↓` | 在书籍间导航 |
| `Enter` | 打开选中的书籍 |
| `Delete` | 移除选中的书籍 |
| `Ctrl/Cmd + A` | 选择所有书籍 |
| `Ctrl/Cmd + Click` | 选择多本书籍 |
| `Shift + Click` | 选择一系列书籍 |
| `T` | 为选中书籍添加/编辑标签 |

## 阅读器导航

| 快捷键 | 操作 |
|----------|--------|
| `→` 或 `空格` | 下一页 |
| `←` 或 `Shift+空格` | 上一页 |
| `[` | 上一章 |
| `]` | 下一章 |
| `T` (Ctrl/Cmd+T) | 切换目录 |
| `B` (Ctrl/Cmd+B) | 切换侧边栏 |

## 文本选择和标注

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl/Cmd + C` | 复制选中文本 |
| `Ctrl/Cmd + F` | 在书内搜索 |

## AI 功能

*注意：AI 相关快捷键在使用苏格拉底模式或 AI 对话时可用。*

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl/Cmd + I` | 切换 AI 面板 |

## TTS 控制

| 快捷键 | 操作 |
|----------|--------|
| *TTS 控制可通过 TTS 界面使用* |

## 视图和布局

| 快捷键 | 操作 |
|----------|--------|
| `F11` 或 `Ctrl/Cmd + Enter` | 切换全屏 |
| `Ctrl/Cmd + =` | 增大字体大小 |
| `Ctrl/Cmd + -` | 减小字体大小 |
| `Ctrl/Cmd + 0` | 重置字体大小 |

## 侧边栏面板

*注意：侧边栏面板可通过阅读器工具栏或以下快捷键切换：*

| 快捷键 | 操作 |
|----------|--------|
| `B` (Ctrl/Cmd+B) | 切换侧边栏 |
| `T` (Ctrl/Cmd+T) | 显示目录 |

*其他面板（标注、搜索、AI 对话）可通过侧边栏界面访问。*

## 自定义快捷键

目前，键盘快捷键无法自定义。如果您需要不同的快捷键，请在我们的 [GitHub Issues](https://github.com/codedogQBY/ReadAny/issues) 页面提交功能请求。

## 平台特定说明

### macOS
- 大多数快捷键使用 `Cmd` 而不是 `Ctrl`
- 某些系统级快捷键可能会覆盖 ReadAny 快捷键

### Windows/Linux
- 应用标准 `Ctrl` 快捷键
- 某些 Linux 桌面环境可能会拦截特定快捷键

## 无障碍功能

所有键盘可访问的功能也可通过屏幕阅读器和其他辅助技术获得。界面遵循标准的无障碍指南进行键盘导航。
