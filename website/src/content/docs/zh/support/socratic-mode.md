## 概述

苏格拉底模式是 ReadAny 独特的 AI 驱动学习功能，采用苏格拉底方法，通过发人深省的问题引导你阅读书籍，而不是直接给出答案。这种方法有助于培养批判性思维和更深入的理解。

## 什么是苏格拉底模式？

与传统提供直接答案的 AI 聊天不同，苏格拉底模式：
- **提出引导性问题**，帮助你自己发现见解
- **鼓励批判性思维**，而非被动阅读
- **根据你的回答进行调整**，提供个性化指导
- **通过对话逐步建立理解**

## 启用苏格拉底模式

1. 打开 **设置 → AI**
2. 在 **对话模式** 下，选择 **苏格拉底**
3. 配置苏格拉底设置：
   - **启用预热**：允许 AI 在你开始阅读前准备上下文
   - **预热策略**：选择 AI 准备方式（自动/智能/手动）
4. 点击 **保存**

## 使用苏格拉底模式

### 开始阅读会话

1. 打开图书馆中的任意书籍
2. 苏格拉底界面将自动出现（如果已启用）
3. 你将看到：
   - 当前章节内容
   - AI 生成的引导性问题
   - 你的回答区域

### 与 AI 互动

**AI 会向你提出如下问题：**
- "你认为作者在这段话中是什么意思？"
- "这个概念与我们之前讨论的内容有何关联？"
- "你能识别出这段的主要论点吗？"
- "有什么证据支持这一主张？"

**你的回答：**
- 在回答区域输入你的想法
- AI 将分析你的回答
- 后续问题会根据你的理解程度进行调整
- 没有对错之分——关键在于探索

### 问题类型

苏格拉底 AI 生成不同类型的问题：

| 类型 | 目的 | 示例 |
|------|---------|---------|
| **理解** | 检查理解程度 | "这里的主要思想是什么？" |
| **分析** | 深化洞察 | "为什么角色做出这个选择？" |
| **应用** | 连接概念 | "你如何在现实生活中应用这一点？" |
| **评估** | 批判性判断 | "你同意作者的结论吗？" |
| **综合** | 结合想法 | "这与第3章有何关联？" |

## 预热策略

预热允许 AI 在你接触文本之前准备上下文，使对话更相关、更有洞察力。

### 自动策略
- **何时**：每个新章节自动激活
- **最适合**：初学者或复杂文本
- **行为**：总是准备上下文，无需询问

### 智能策略
- **何时**：仅在你尚未看过预热对话框时激活
- **最适合**：希望提高效率的常规读者
- **行为**：每本书显示一次预热对话框，然后静默工作

### 手动策略
- **何时**：仅在你明确触发时
- **最适合**：希望完全控制的高级用户
- **行为**：从不自动激活；由你决定何时预热

## 有效使用技巧

### 对于学习者
1. **慢慢来** - 不要急于回答问题
2. **深入思考** - 回答前仔细反思
3. **诚实作答** - 说"我不理解"是可以的
4. **请求澄清** - 如果问题不清楚，请说明
5. **建立联系** - 将新想法与你已知的知识联系起来

### 对于教育者
1. **用作教学辅助** - 补充课堂讨论
2. **跟踪进度** - 回顾对话历史以评估理解程度
3. **自定义难度** - 通过反馈调整问题复杂度
4. **鼓励反思** - 使用后续问题深化思考

### 对于读书会
1. **生成讨论话题** - 使用 AI 问题作为对话起点
2. **比较解读** - 不同成员可以分享他们的回答
3. **探索主题** - 让 AI 引导探索关键主题
4. **会议准备** - 在小组讨论前使用苏格拉底模式

## 高级功能

### 上下文感知

苏格拉底 AI 理解：
- 你当前的阅读位置
- 你之前读过的章节
- 你过去的回答和理解水平
- 书籍元数据（类型、复杂度、主题）

### 自适应难度

AI 根据以下因素调整问题复杂度：
- 你的回答质量
- 阅读速度
- 参与程度
- 明确反馈

### 对话历史

所有苏格拉底对话都会被保存：
- 从侧边栏访问过去的对话
- 回顾你的学习历程
- 导出对话作为学习笔记
- 恢复之前的讨论

## 故障排除

### AI 不提问

**问题**：AI 提供直接答案而不是问题。

**解决方案**：
1. 验证设置 → AI 中已启用苏格拉底模式
2. 检查 API 密钥是否有效
3. 尝试重启阅读器
4. 确保使用能力强的模型（GPT-4、Claude 等）

### 问题太简单/太难

**问题**：问题不符合你的水平。

**解决方案**：
1. 提供反馈："这太简单了"或"这太难了"
2. AI 会随着时间的推移进行调整
3. 尝试不同的书籍以重置上下文
4. 在设置中手动调整难度（如果可用）

### 预热不起作用

**问题**：预热未按预期激活。

**解决方案**：
1. 检查预热策略设置
2. 对于智能策略：清除设置中的"已显示对话框"标志
3. 对于手动策略：在工具栏中寻找预热按钮
4. 验证 AI 提供商配置正确

## 最佳实践

### 入门指南
1. 从熟悉的书籍开始以了解流程
2. 自然回答 - 不要过度思考
3. 尝试不同的问题类型
4. 定期回顾对话历史

### 最大化学习效果
1. 持续使用 - 定期练习 improves 结果
2. 记录你发现的见解
3. 在 AI 指导下重新审视具有挑战性的段落
4. 与传统笔记结合使用

### 避免常见陷阱
1. 不要将其视为测验 - 没有评分
2. 不要跳过问题 - 每个问题都建立在前一个基础上
3. 不要期望立即掌握 - 学习需要时间
4. 不要用于简单的事实查询 - 使用常规 AI 聊天

## 对比：苏格拉底模式 vs 常规聊天

| 特性 | 苏格拉底模式 | 常规聊天 |
|---------|--------------|--------------|
| **方法** | 提出问题 | 提供答案 |
| **目标** | 发展思维 | 获取信息 |
| **最适合** | 学习和理解 | 快速事实和摘要 |
| **交互** | 多轮对话 | 问答格式 |
| **深度** | 深入探索 | 表面级答案 |
| **时间** | 花费更长时间 | 更快的响应 |

## 何时使用苏格拉底模式

✅ **使用苏格拉底模式：**
- 学习复杂教科书
- 分析文学作品
- 哲学文本
- 学习新科目
- 培养批判性思维
- 深度阅读会话

❌ **使用常规聊天：**
- 快速事实检查
- 总结章节
- 翻译请求
- 简单定义
- 时间敏感的查询

## 键盘快捷键

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl/Cmd + I` | 切换苏格拉底面板 |
| `Enter` | 提交回答 |
| `Shift + Enter` | 回答中新起一行 |
| `Esc` | 关闭面板 |

## 反馈和改进

苏格拉底 AI 从你的互动中学习：
- 评价回答（点赞/点踩）
- 提供文本反馈
- 报告不当问题
- 建议更好的问题

你的反馈有助于改善未来的会话。

## 隐私

所有苏格拉底对话：
- 存储在您的设备本地
- 不会发送到 ReadAny 服务器
- 仅使用您配置的 AI 提供商
- 可以随时删除
- 包含在数据导出选项中
