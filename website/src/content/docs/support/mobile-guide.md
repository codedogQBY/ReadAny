## Overview

ReadAny is now available on mobile devices! This guide covers everything you need to know about using ReadAny on iOS and Android, including mobile-specific features and optimizations.

## Platform Support

### iOS
- **Minimum Version**: iOS 15.0+
- **Devices**: iPhone, iPad
- **Installation**: TestFlight (beta) or App Store (coming soon)

### Android
- **Minimum Version**: Android 8.0+
- **Devices**: Phones, Tablets
- **Installation**: Google Play Store (coming soon) or APK

## Mobile-Specific Features

### 1. Floating TTS Bubble 🎈

**What it is**: A floating bubble that shows TTS playback status and provides quick controls.

**Features**:
- Always visible during TTS playback
- Quick play/pause toggle
- Skip forward/backward buttons
- Drag to reposition
- Tap to expand full controls

**How to use**:
1. Start TTS playback
2. Floating bubble appears automatically
3. Drag to preferred position
4. Tap for expanded controls
5. Dismiss by stopping TTS

**Best for**:
- Multitasking while listening
- Quick access to TTS controls
- Background listening

### 2. TTS Mini Player 🎵

**What it is**: A compact TTS player that integrates with your device's media controls.

**Features**:
- Lock screen controls
- Notification center integration
- Bluetooth headset controls
- Background playback
- Auto-resume on app reopen

**How to use**:
1. Start TTS playback
2. Lock your device or switch apps
3. Use system media controls
4. Control from lock screen or notification
5. Resume by reopening app

**Best for**:
- Listening while commuting
- Workout sessions
- Bedtime reading
- Long listening sessions

### 3. Tag Management Sheet 🏷️

**What it is**: Mobile-optimized interface for managing book tags.

**Features**:
- Swipe-to-edit tags
- Quick tag creation
- Visual tag browser
- Bulk tag operations
- Search and filter by tags

**How to use**:
1. Go to Library screen
2. Tap the Tags button
3. View all tags in sheet
4. Tap tag to filter books
5. Long-press to edit/delete

**Best for**:
- Organizing large libraries
- Quick book categorization
- Finding books by topic
- Managing reading lists

### 4. WebDAV Import Browser 📚

**What it is**: Integrated file browser for importing books from WebDAV servers.

**Features**:
- Browse WebDAV directories
- Preview book metadata
- Batch import selection
- Progress tracking
- Conflict resolution

**How to use**:
1. Tap Import button in Library
2. Select "WebDAV Import"
3. Connect to your WebDAV server
4. Browse and select books
5. Tap Import to download

**Best for**:
- Importing from cloud storage
- Accessing remote libraries
- Syncing book collections
- Backup restoration

### 5. Vectorization Queue ⚡

**What it is**: Smart queue system for managing book vectorization on mobile devices.

**Features**:
- Automatic queue management
- Battery-aware processing
- WiFi-only option
- Progress notifications
- Pause/resume capability

**How to use**:
1. Import books normally
2. Vectorization starts automatically (if enabled)
3. Monitor progress in notification
4. Pause if needed to save battery
5. Resume when convenient

**Best for**:
- Large library imports
- Battery conservation
- Offline preparation
- Semantic search readiness

## Troubleshooting Mobile Issues

### App Crashes

**If app crashes**:

2. Check for updates
3. Clear app cache
4. Reinstall if persistent

### TTS Not Working

**If TTS doesn't work**:

3. Restart TTS service

## FAQ

### Can I use ReadAny offline?

Yes! Once books are imported, you can read offline. TTS works with system voices. Sync requires internet.

### Does it work on tablets?

Absolutely! ReadAny is optimized for both phones and tablets, with adaptive layouts.

### How much storage does it need?

Depends on your library. Typical book: 1-5MB. Plan for 100MB-1GB based on library size.

### Can I sync between mobile and desktop?

Yes! Use WebDAV or S3 sync to keep progress and annotations in sync across devices.

### Is there a limit on devices?

No limit! Install on as many devices as you want. Sync keeps everything consistent.
