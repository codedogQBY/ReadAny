## Global Shortcuts

These shortcuts work throughout the application:

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + O` | Open/Import books |
| `Ctrl/Cmd + F` | Search in library |
| `Ctrl/Cmd + ,` | Open Settings |
| `Ctrl/Cmd + Q` | Quit ReadAny |
| `F1` | Open Help Documentation |

## Library View Shortcuts

| Shortcut | Action |
|----------|--------|
| `↑` / `↓` | Navigate between books |
| `Enter` | Open selected book |
| `Delete` | Remove selected book(s) |
| `Ctrl/Cmd + A` | Select all books |
| `Ctrl/Cmd + Click` | Select multiple books |
| `Shift + Click` | Select range of books |
| `T` | Add/edit tags for selected book |

## Reader Navigation

| Shortcut | Action |
|----------|--------|
| `→` or `Space` | Next page |
| `←` or `Shift+Space` | Previous page |
| `[` | Previous chapter |
| `]` | Next chapter |
| `T` (Ctrl/Cmd+T) | Toggle Table of Contents |
| `B` (Ctrl/Cmd+B) | Toggle sidebar |

## Text Selection and Annotation

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + C` | Copy selected text |
| `Ctrl/Cmd + F` | Search within book |

## AI Features

*Note: AI-related shortcuts are available when using Socratic Mode or AI Chat.*

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + I` | Toggle AI panel |

## View and Layout

| Shortcut | Action |
|----------|--------|
| `F11` or `Ctrl/Cmd + Enter` | Toggle fullscreen |
| `Ctrl/Cmd + =` | Increase font size |
| `Ctrl/Cmd + -` | Decrease font size |
| `Ctrl/Cmd + 0` | Reset font size |

## Sidebar Panels

*Note: Sidebar panels can be toggled via the reader toolbar or the following shortcuts:*

| Shortcut | Action |
|----------|--------|
| `B` (Ctrl/Cmd+B) | Toggle sidebar |
| `T` (Ctrl/Cmd+T) | Show Table of Contents |

*Other panels (Annotations, Search, AI Chat) are accessible via the sidebar interface.*

## Customizing Shortcuts

Currently, keyboard shortcuts cannot be customized. If you need different shortcuts, please submit a feature request on our [GitHub Issues](https://github.com/codedogQBY/ReadAny/issues) page.

## Platform-Specific Notes

### macOS
- Use `Cmd` instead of `Ctrl` for most shortcuts
- Some system-level shortcuts may override ReadAny shortcuts

### Windows/Linux
- Standard `Ctrl` shortcuts apply
- Some Linux desktop environments may intercept certain shortcuts

## Accessibility

All keyboard-accessible features are also available through screen readers and other assistive technologies. The interface follows standard accessibility guidelines for keyboard navigation.
